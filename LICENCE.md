## 🧩 About

**World War 3 helpers** is a curated list of World War 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap enhancements, HUD tweaks
- **Quality-of-Life Helpers** — loadout manager, config presets, overlay notes
- **Research Notes** — map layouts and configuration notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Custom HUD Overlay — show player stats and match info on screen
- overlay Notes — visualize teammate and objective positions
- Loadout Manager — save and switch weapon configurations
- Playback Speed — adjust game speed in offline practice (0.1x to 5x)

### 🎨 Visual & UI
- Color Customization — tweak UI colors and crosshair styles
- Skin Manager — organize weapon skins and camos
- Streamer Mode — hide sensitive information on screen

### 🗺️ Map & Tactics
- Map Overlay — display tactical map with callouts
- Marker System — place custom markers in practice mode
- Session Notes — record and review match statistics
